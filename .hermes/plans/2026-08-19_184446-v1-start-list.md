# V1 Start List + PDF Implementation Plan

> **For Hermes:** Implement task-by-task with TDD. Fresh rebuild. Do not reuse `app/` or old tests except as read-only reference. Do not scrape AskFRED HTML. Never print `.env` secrets.

**Goal:** Local phone web app: search an upcoming tournament, show Elite Fencers Club people under each event by day, download that same list as a PDF.

**Architecture:** New `fencer_schedules/` package. AskFRED official API = catalog + events + “is this USFA?” via `registration_url`. USFA public pages = names for regional/national. One SQLite file holds the loaded tournament and extra tracked fencers. Jinja2 phone page; PDF is an export of the same schedule model.

**Tech Stack:** Python 3.12 via `uv`, FastAPI, SQLAlchemy 2 + SQLite, Jinja2, httpx, pydantic v2, pydantic-settings, fpdf2, pytest, respx. Launch with `./run.sh` (never `env -i`).

**Spec:** `PRODUCT.md`. Evidence: `FEASIBILITY.md`. Interview record: `revive-spec.md` (do not treat as acceptance).

**Out of this plan:** FTL, FencingTracker, AskFRED `/preregistrations` scrape, app accounts, live strips/results.

**Human blocker:** none for v1. `ASKFRED_API_TOKEN` is already in gitignored `.env`.
